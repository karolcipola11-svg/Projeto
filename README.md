# Projeto

Site institucional da **MSE Marmoraria**, publicado automaticamente pelo GitHub
Pages. Não é preciso instalar editor, abrir terminal ou baixar arquivos.

## Abrir a prévia pelo tablet

1. Abra a página deste pull request no GitHub.
2. Role até a caixa **Deployments**, na lateral direita.
3. Toque em **github-pages** e depois em **View deployment**.

O botão aparece assim que a publicação automática termina. A mesma prévia é
atualizada a cada novo envio para a branch principal.
