# Site MSE Marmoraria

Site institucional responsivo e pronto para publicação na Hostinger.

## Personalizar antes de publicar

1. **WhatsApp:** altere `WHATSAPP_NUMBER` no início de `script.js`. Informe código do país, DDD e número sem espaços ou símbolos.
2. **Fotos:** siga `images/README.md` para inserir as fotos reais da MSE.
3. Confira os horários e dados de atendimento em `index.html` antes de publicar.

## Publicar na Hostinger

1. No hPanel, abra **Sites → Gerenciar → Gerenciador de arquivos**.
2. Abra a pasta `public_html` e remova a página padrão da hospedagem.
3. Envie `index.html`, `styles.css`, `script.js` e a pasta `images` para `public_html`.
4. Confirme que `index.html` está diretamente dentro de `public_html` e abra o domínio.

O site usa somente HTML, CSS e JavaScript: não precisa de instalação ou processo de build.
