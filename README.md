# Projeto

## Abrir uma prévia no navegador (sem mexer em código)

1. Abra este projeto no **Visual Studio Code**.
2. No menu superior, clique em **Terminal**.
3. Clique em **Executar Tarefa...**.
4. Clique em **Prévia: abrir site no navegador**.

O navegador será aberto automaticamente em `http://localhost:4173`. Mantenha o
terminal da tarefa aberto enquanto estiver visualizando o site. Para encerrar a
prévia, volte ao VS Code, clique dentro desse terminal e pressione **Ctrl+C**.

> Se o navegador estiver configurado para bloquear janelas abertas por outros
> programas, clique no endereço azul `http://localhost:4173` exibido no terminal.
